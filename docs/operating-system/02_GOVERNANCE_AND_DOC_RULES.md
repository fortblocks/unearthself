# Governance and Documentation Rules

**Version:** 1.1 — 8 September 2026

The partnership is flat. The remits below are how work is divided, not a hierarchy. Anyone can challenge a decision. Only the named owner may close the file that sits in their remit.

## How the remits meet

```
Tess        product / modality / facilitation
Lisa        the day, the guest, the land
Norah       the money, the treatments, the practitioners
Christopher the systems, the brand, the market, the site and app
```

A Bootcamp day needs all four. Tess designs what happens. Lisa makes the house able to hold it. Norah prices it and staffs the spa. Christopher puts it on the site, in the CRM, and in front of a buyer — with Tess on the sales conversation.

## Source-of-truth rules

1. Project files in `docs/operating-system/` beat conversation history.
2. The Master Index PDF is an archive. Quote a page if you must; do not treat the whole document as current.
3. `Unearth Self MVP.pdf` pages 1–19 are the current retreat architecture. Later pages contain earlier drafts. Prefer the PACE + Existence version.
4. Seed rune names in `Badlands Bootcamp - Seeds.pdf` are retired. Keep the glyphs. Do not keep Super Empathy / Unbreakable Integrity etc. as public product names.
5. When a fact changes, update the relevant file and add a dated line to the Changelog at the bottom of that file.
6. Specialist chats may only edit their assigned file plus, if needed, a note in `17_OPEN_DECISIONS.md`.
7. Never silently “fix” an open decision. Flag it.

## How to spawn a specialist chat

Use the prompt in `16_CHAT_SPAWN_PROMPTS.md`. Every spawned chat must:

- Name the workstream
- List the files it has read
- State what it will not touch
- Return a short decision log, not a novel

## Cadence

- Weekly partner stand-up against the roadmap workbook
- Daily sales bot digest to Christopher and Tess (enquiries, pipeline, unanswered)
- Friday numbers from Norah
- After every paid pilot: Tess updates the retreat file with what actually happened; Lisa files incidents and house notes
