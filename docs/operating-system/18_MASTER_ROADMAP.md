## Critical path (if only five things happen)

1. Rate card inputs filled by partners (D01) — nothing public prices without this.
2. Booking tools chosen and embedded (D03, D04).
3. Website v1 that books, not essays.
4. Safety pack + insurance (D13) before the first paid outdoor day.
5. One named facilitator who can run PACE without inventing Tuesday morning.

Everything else is important. Those five are load-bearing.
